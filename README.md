# Drum Kit Project  

This is a simple Drum Kit project built using **HTML, CSS, and JavaScript**.  
It allows users to play drum sounds by either clicking on the drum buttons or pressing specific keys on the keyboard.  

## Features
- Play different drum sounds with mouse clicks  
- Play drum sounds with keyboard keys  
- Simple and interactive user interface  
- Responsive design for desktop and mobile  

## How to Run
1. Download or clone the repository.  
2. Open the `index.html` file in any browser.  

## Technologies Used
- HTML  
- CSS  
- JavaScript
